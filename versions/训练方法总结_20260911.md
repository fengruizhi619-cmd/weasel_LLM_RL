# 训练方法总结（2026-09-11）

针对「小狼毫 + LLM 联想」这条路的训练方法，从「奖励式在线学习」一路查到
「交叉熵 + 小步长 + 混料」，下面是定稿的配置、支撑每条结论的实验数据，以及
还没有验证的部分。

---

## 一、结论速览

| 结论 | 证据 |
|---|---|
| 骨干用 **Base**，不用 chat 版 | 同流程训练后，小说留出命中 73.8% vs 70.7%，top1 42.5% vs 39.0%，平均 CE 3.54 vs 3.91 |
| 损失用**纯交叉熵**（不再用排名奖励） | 损失打在真值 token 上把命中率从 66% 抬到 83%；阶梯方向（正挂/倒挂/无权重）三者无差别 |
| 优化器用**普通梯度下降** | AdamW 会按参数归一化，奖励乘常数完全不影响更新，等于把「奖励决定步长」这件事抹掉 |
| 学习率压到 **1e-5** | 极化（前20累计概率）随 lr 单调：5e-4 时 +0.17，1e-5 时 0.00 |
| **混料 25%** 打字数据 | 同剂量下，小说收益几乎不损失，打字域从 −5.5 点翻成 +5 点 |
| 梯度裁剪必须关 | 范数裁剪等于变相归一化，会把 rank-1 和 rank-20 的步长拉平 |

**尚未验证**：超大数据量下的泛化。当前最大剂量是 1 万字小说 + 17001 步，
同域数据提高约 3 个百分点（内部 74.3%→77.4%，留出 70.5%→73.6%），但**更大
数据量下会不会出现真正的泛化，还没有测过**。

## 二、最终配置

```
损失      loss = -log p(真值 token)          每个非标点位置一步，纯交叉熵
优化器    torch.optim.SGD                    无动量
学习率    1e-5                               WEASEL_LLM_LR 可覆盖
梯度裁剪  关闭（0）                          开启会抹平奖励/排名带来的步长差异
混料比例  打字 : 小说 = 25 : 75               打字池 = 在线 accept + 离线 commit，去重
标点      不参与打分，且不打断最长链
数据源    小说正文按 400 字分块、前 64 字作上下文，逐 token teacher forcing
```

---

## 三、评估口径（三个指标）

在整段文本上逐 token 游走（冻结主干、teacher forcing、标点跳过）：

1. **前20累计概率**：每个位置 top-20 概率之和的平均值。候选表占多少概率质量，
   也是**极化**的探针（配合 lr 一起看）。
2. **命中率 / 脱靶率**：真值 token 落在 top-20 里的位置占比；脱靶率 = 1 − 命中率。
3. **最长链**：连续命中的最长 token 数。

辅助列：top1 / top5 命中率、权重位移（RMS(ΔW)/RMS(W)）。

## 四、关键实验

### 4.1 损失函数：奖励式 → 交叉熵

早期方案把损失打在「模型自己提出的候选」上（带字符级部分匹配 + 排名阶梯
100%…5%）。1 万字 / 423 步的对照：

| 打分对象 \ 权重方向 | 正挂 | 倒挂 | 无权重 |
|---|---|---|---|
| 模型自己的候选 | 66.4% | 68.0% | — |
| **真值 token** | **83.4%** | 82.2% | 81.8% |

（训练文本命中率，基线 68.2%）

**归因**：唯一的决定因素是「损失打在谁身上」；排名阶梯的方向差异在噪声内，
无权重（纯 CE）与两者持平。所以阶梯整个删掉。

### 4.2 优化器：AdamW → SGD

AdamW 的更新是 `lr · m̂/(√v̂+eps)`——奖励整体乘常数时分子分母同比例变化，
**更新完全不变**；相对差异也被二阶矩压平。而 AdamW 还会把每一步抬到接近满
步长，与奖励大小无关，12799 步之后把头的判别力磨掉（留出 top5 48.1%→22.9%，
前 20 词表 1253→848，标点平均排名 1.2→153）。

换成 SGD 后，实测步长严格正比于权重：

| 权重 | 单步 \|dW\|_F | 相对 |
|---|---|---|
| 1.00 | 3.8892e-02 | 1.0000 |
| 0.95 | 3.6948e-02 | 0.9500 |
| 0.50 | 1.9446e-02 | 0.5000 |
| 0.05 | 1.9446e-03 | 0.0500 |

### 4.3 学习率：极化随 lr 单调

1 万字小说、5313 步、只改 lr（留出文本 = 第 11 章起 2000 字）：

| lr | 权重位移 | 留出 命中 / 累计p / top1 | 打字域 top1 |
|---|---|---|---|
| 基线 | 0 | 70.5% / 0.7366 / 40.2% | 14.5% |
| 5e-4 | 0.660% | 67.4% / 0.9126 / 35.6% | 8.0% |
| 1e-4 | 0.150% | 73.0% / 0.7794 / 41.2% | 8.5% |
| 3e-5 | 0.064% | 74.1% / 0.7465 / 41.4% | 11.0% |
| 1e-5 | 0.028% | 73.2% / 0.7342 / 41.8% | 10.5% |
| 3e-6 | 0.011% | 72.2% / 0.7326 / 41.4% | 13.0% |

累计概率的变化与 lr 几乎成正比（+0.173 / +0.047 / +0.013 / −0.000 / −0.003），
**到 1e-5 极化完全消失**。5e-4 不是「剂量大」而是「过冲」——它的收益反而比
1e-4 小。

### 4.4 混料比例（打字 : 小说）

固定总步数 3000、lr 1e-5，打字评估集是**从未参与训练的 200 条**：

| 打字占比 | 小说内部 命中 | 小说留出 命中 / 累计p | 打字 top1 / top5 |
|---|---|---|---|
| 基线 | 74.3% | 70.5% / 0.7366 | 14.5% / 27.5% |
| 0% | 76.5% | 72.4% / 0.7289 | 11.0% / 26.5% |
| **25%** | 76.8% | 72.0% / 0.7436 | **19.0% / 31.0%** |
| 50% | 76.7% | 71.9% / 0.7708 | 20.0% / 34.0% |
| 100% | 73.6% | 69.2% / 0.8303 | 20.0% / 35.5% |

**25% 是甜点**：混料在小说侧几乎免费（0%/25%/50% 的留出命中 72.4/72.0/71.9），
打字域则从「纯小说训练掉 3.5 点」翻成「涨 4.5 点」。100% 纯打字会把小说带崩，
且极化最重。

**数据预算**：打字池去重后约 2800~2900 步；25% 比例下「各用一遍」可干净匹配
约 1.7 万字小说。超出就得复读，而复读会推尖（100% 那臂复读 3.7 遍 → 累计概率
+0.094）。

### 4.5 骨干：Base vs Chat（本轮唯一的选型实验）

同语料、同步数（17001）、同 lr（1e-5）、同比例（24.4%）、同随机种子，两臂都从
**各自模型的原始头**开始训练，唯一变量是骨干：

| 骨干 | 阶段 | 留出 命中 / top1 / 链 | 打字 top1 | 平均 CE |
|---|---|---|---|---|
| **Base** | 训练前 | 71.6% / 40.2% / 17 | 14.5% | — |
| **Base** | 训练后 | **73.8% / 42.5% / 17** | 10.5% | **3.54** |
| Chat | 训练前 | 68.0% / 36.2% / 15 | 12.5% | — |
| Chat | 训练后 | 70.7% / 39.0% / 12 | 13.0% | 3.91 |

Base 在小说域领先 3 个命中点 / 3.5 个 top1，且同样数据下 CE 更低（拟合更顺），
说明它的表征更贴合这个场景。Chat 的唯一优势是打字域不掉分（+0.5 vs −4.0）——
因为它被 SFT 推向「助手式文本」，而用户打字恰好就是那一类；但小说是描述性
叙事，正是它的弱项。Chat 的分布还天生更尖（累计概率 0.789 vs 0.756）。
**换骨干要往更大的 Base 走，不是 chat 版。**

### 4.6 两个域的冲突程度

对 head 分别求两个域的平均梯度：**cos(打字, 小说) = +0.11**——近乎正交、略同向。
一阶上两者不打架（这份 head 原则上能同时服务两边），打字域掉分主要来自二阶
效应（打字域最优点很尖，步长抖动就会掉），所以降 lr 有效、混料有效，而
「拆成两份 head」没有必要。

### 4.7 真实混料训练（17001 步，已落盘）

第 1~10 章 24289 字 + 打字池 2862 条去重、lr 1e-5、打字占比 24.4%、复读 1.6 遍：

| | 训练前 | 训练后 | 变化 |
|---|---|---|---|
| 小说内部 命中 | 74.3% | 77.4% | **+3.1** |
| 小说留出 命中 / top1 | 70.5% / 40.2% | **73.6% / 42.3%** | **+3.1 / +2.2** |
| 小说留出 累计p | 0.7366 | 0.7559 | +0.019（可控） |
| 打字域 top1 | 14.5% | 12.0% | −2.5 |

权重只动了 **0.054% of std**，就换来同域 +3 个点；极化 +0.019 远小于 5e-4 时的
+0.176。

## 六、已知问题与后续

1. **打字域退化没有被彻底解决**：混料 25% 能大幅缓解，但在大剂量小说训练下
   仍会净负（−2.5 点）。要根治只能持续扩充打字池，或定期用打字数据回放。
2. **复读会推尖**：打字池被重复使用的遍数越多，前20累计概率越高。建议单次训练
   的小说文本量控制在「打字池 × 3」以内。
3. **超大数据下的泛化未验证**（本总结里唯一没做的实验）。当前证据只到 1 万字
   / 17001 步，同域 +3 点、跨域（第 11 章起）也是 +3 点，但**跨到别的书、
   别的文体会怎样，没有任何数据**。
4. 代码在本轮做了大量改动（损失、优化器、混料、删死代码），**尚未提交 git**。
